
# CodeAlpha Project 1: Language Translation Tool

## Overview
This project is a language translation application developed using Python and Streamlit. It uses Argos Translate to translate text between supported languages using locally installed translation models.

## Features
- Simple and user-friendly interface
- Source and target language selection
- Text translation
- Download translated text
- Local translation after model installation

## Technologies Used
- Python
- Streamlit
- Argos Translate

## Installation

1. Clone or download this repository.
2. Open the project folder in Command Prompt.
3. Create and activate a virtual environment.
4. Install the required packages:

   pip install -r requirements.txt

5. Install the translation models:

   python setup_models.py

6. Start the application:

   python -m streamlit run app.py

## How to Use
1. Select the source language.
2. Select the target language.
3. Enter the text.
4. Click Translate Text.
5. View or download the translated result.
